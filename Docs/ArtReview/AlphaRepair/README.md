# 2026-08-28: 원화 보존 알파 수정

사용자가 승인한 Python 알파 수정 방식으로 적용했다. 얼굴·비율·선화의 RGB 값과 캔버스 크기는 변경하지 않았다. 거부된 생성 보정본은 사용하지 않았다.

적용한 기존 LD 10장:

- 기본 2, 10, 14, 16, 20, 24단계
- 스킨 lv01-a, lv01-b, lv04-a, rose-oath

각 이미지의 원본은 `Originals`, 적용본은 `Cleaned`, 변경 영역은 `Masks`에 보관했다. `repair-report.json`에는 적용 여부, 전후 SHA256, 변경한 알파 픽셀 수와 선택한 배경 영역이 기록되어 있다. `*-dark.jpg`, `*-light.jpg`는 원본/수정본 비교다.

14단계 팔 안쪽, 20단계 백발 안쪽, rose-oath 머리카락 사이의 체크무늬를 확인하고 수정했다. 백발의 얇은 머리카락을 자를 수 있는 넓은 경계 처리는 제외했다. 은색 장비·옷·칼날의 흰 하이라이트는 배경으로 일괄 제거하지 않았다.

기존 LD 전체 조사 대상은 44장이다. 이번에 확대 확인하고 수정한 것은 위 10장이며, 나머지 34장의 최종 확대 검수까지 끝났다는 의미는 아니다. 25단계 이후는 수정하지 않았다.

`protected-hashes.json`은 수정 직전 기존 LD 메타데이터 44개와 플레이어 세이브의 해시다. `Docs/UIRefresh/verify_skin_batch.py`로 원본 RGB, 적용본 해시, 메타데이터 및 세이브 보존을 재검증한다. 그림의 자연스러움은 픽셀 검사만으로 보증하지 않는다.
