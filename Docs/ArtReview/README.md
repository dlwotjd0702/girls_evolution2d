# SD·LD 검수 및 적용 기록

## 2026-08-28 최종 적용

**1~24단계 SD·LD 48장을 대조했다. 25단계와 그 이후 형태는 사용자 요청으로 제외하고 기존 LD 공용 구조를 유지했다.**

머리 모양·색, 복장 실루엣, 얼굴 가림, 무기·소품을 기준으로 검수했다. 캐릭터 정체성이 대응한다는 판정이며 모든 장식·포즈·손가락의 완벽한 동일함을 의미하지 않는다. 기존 1·3·4·5·18·21·22는 유지했다. 8·9는 아래 오류를 정정했다.

### LD 15장 재작화 적용 완료

- 적용 단계: **2·6·7·10·11·12·13·14·15·16·17·19·20·23·24**.
- 기존 초안 12장에 7·11·12를 추가했다. 이 세 단계의 이전 ‘일치’ 판정을 확대 검수 후 정정했다.
- 7: 짧은 갈색 트윈테일, 닫힌 도복과 회색 띠. 11: 분홍 목도리·넓은 소매·연기. 12: 청록 앞머리·땋은 머리·초록 짧은 하의.
- 최종 게임 파일: [Assets/Art/Characters/LD](../../Assets/Art/Characters/LD/). 원래 LD 파일은 삭제하거나 덮어쓰지 않았다.
- 생성 방식: **built-in imagegen**. 정확한 지시문: [기존 12장](Redraws/prompts.json), [추가 3장](Redraws/additional-prompts.json). CLI 이미지 생성은 사용하지 않았다.
- 생성 결과의 불투명 체크무늬/흰 배경은 사용자 동의 후 로컬 처리했다. 외부 배경과 검수한 내부 빈 공간을 제거하고 윤곽의 밝은 번짐을 정리했다. [처리 스크립트](refine_cutouts.py), [알파 보고서](Cutouts/alpha-report.json).
- `Redraws`는 생성 원본, `Cutouts`는 처리·검수 산출물이다. 게임은 Assets의 최종 PNG만 사용한다.
- 기존 캐릭터 ID, CSV, 합성·환생 규칙은 이번 원화 작업에서 변경하지 않았다.

### 8·9단계 이전 수정 오류 정정

원본 `닌자SD2/8.png`는 오색 기모노, `닌자SD2/9.png`는 검은 도복으로 **원본은 정상이었다**. 이전 작업의 ‘서로 뒤바뀌어 있다’는 판정과 복사본 교체가 잘못됐다. 최종 비교에서 발견하여 `Art/Characters/SD/8.png`, `9.png`의 내용을 같은 번호의 원본으로 복구했다. 주소와 GUID는 유지했다.

기존 검사는 연결 경로만 확인해 이 문제를 잡지 못했다. 이제 PNG 바이트가 검수한 원본과 동일한지도 검사한다. 9단계는 검은 머리·회색 도복 테마가 대응하지만 머리 묶음과 종이 소품의 표현 차이는 남아 있다.

## 검증

- Unity 2022.3.62f3 편집기 컴파일 및 **288개 회귀 검사 통과**. [전체 결과](regression-checks.txt).
- 15 LD의 실제 투명 알파·빈 테두리·주소·Sprite.name·도감 LD/필드 SD 선택 경로 검사.
- [적용 전](before-sprites.json)과 [적용 후](final-sprites.json) 비교: SD8/9 복사본을 제외한 23 SD 및 교체하지 않은 10 LD의 경로·GUID·PNG 해시 불변. 총 50개 주소 중복 없음. [검사 스크립트](audit_art.py).
- 320×568 Game View의 기존 도감 상세 패널에서 20 LD가 비율을 유지하며 표시되고 체크무늬/흰 사각 배경이 남지 않는 것을 확인했다. 미리보기 후 원래 비활성 상태로 복원했다.
- 사용자 세이브 SHA-256은 작업 전후 `8038F32EB5C757582B5FC2EA3B7B8C240B3CE0BA903D6AC3BF074D2A8FA0C439`로 동일하다.
- 실제 Android 기기, Addressables 플레이어 번들 빌드, 광고·결제 실행은 이번 검증 범위에 포함하지 않았다. 출시 전에 기기에서 화질·메모리·터치감을 추가 검증해야 한다.

## 앞선 UI 보완 유지

- ‘현질’ → ‘상품’. 보석 광고·골드 광고·수익 2배(10분)를 상품 탭 위쪽에 배치하고 일반 화면의 수익 2배 버튼은 제거했다.
- 상품·소환 버튼 높이 200, 소환 행 높이 380. 필드 사용량·빈자리·해금 조건 표시 및 필드 포화 시 소환 비활성화.
- 불필요한 목표 표시를 숨기고 큰 피버 영역을 유지했다. 초당 3회·3초 유지 조건과 수익 보너스를 표시한다.
- 광고 제거 ID는 카탈로그와 같은 `remove_ads`. 실제 결제/광고는 실행하지 않았다.
- 원화 적용 이전 UI 회귀 검사는 240개였으며 최종 288개에 포함된다. 실제 폰 검증을 대체하지 않는다.

## 편집기 재검증

`Tools > Girls Evolution > Art > Apply Reviewed LD`는 15 LD만 연결한다. `Run Progression Checks`로 검증한다. `Preview LD Detail`은 상세 패널 내용만 바꾸므로 도감 상위 패널을 잠시 활성화해야 보인다. 미리보기 씬은 저장하지 말고 상위 활성화를 되돌린 뒤 `Close LD Detail Preview`로 닫는다.
