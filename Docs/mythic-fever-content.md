# 신화 수집·온라인 버프·피버

후속 모바일 UI/아트 전수 검수 변경은 [ArtReview/README.md](ArtReview/README.md) 참조. 기존 목표 HUD는 제거했고 피버·보상 버튼을 크게 분리했다. 최신 편집기 검사 226개 통과.

## 구현 기준

- 1~24단계와 4개 월드, 합성 재료 수 및 가격 공식을 유지한다.
- 현재 회차의 25단계 외형은 벚꽃의 시조 → 월영의 수호자 → 홍련의 봉황 순환이다. 현재 3종이며 무한히 새로운 이미지를 생성하는 기능은 아니다.
- 다음 외형은 환생 후 목표가 되고, 해당 회차에서 25단계에 도달해야 도감에 등록된다. 25단계 누적 강화는 같은 외형의 중복 수집으로 취급하지 않는다.
- 기존 도감 25칸 뒤에 신화 수집 슬롯 3칸을 추가한다. 새 외형은 캐릭터 레벨 26/27로 저장하지 않는다.
- SaveData v4에 외형의 고정 문자열 ID, 발견 목록, 광고 버프 만료 UTC를 추가했다. 기존 세이브는 원래 신화만 소급 인정한다. 목록을 확장할 때 이미 출시한 ID를 바꾸지 않는다.

## 수익 버프

- 캐릭터 클릭을 1초 이동 구간으로 집계한다. 기본 초당 3회 이상을 3초 지속하면 피버 +50%.
- 기준 미달 때 충전이 초당 2초분 감소하며 0에서 종료한다. 포커스 이탈·앱 일시정지·환생·로드 시 피버는 초기화한다. 메뉴 클릭과 자동 합성은 집계하지 않는다.
- 자발적인 광고 완료 보상은 온라인 수익 2배 600초. 취소/실패는 보상 없음. 중복 요청과 중복 콜백은 보상을 중첩하지 않는다.
- 광고 제거 보유자는 같은 시간제 보상을 광고 없이 받는다. 기존 remove_ads 상품만 사용하며 새 상품/가격/실결제는 등록하지 않았다.
- 광고 ×2와 피버 ×1.5가 겹치면 온라인 수익 ×3. 필드 자동 수익 및 캐릭터 클릭 골드에 적용한다.
- 오프라인 보상 추정치, 소환 가격, 환생 포인트, 시작 자금에는 이 배율을 섞지 않는다.
- 광고 버프는 UTC로 만료되므로 게임을 꺼도 시간이 흐른다. 로컬 저장/시계 기반이므로 변조 방지나 서버 검증을 대신하지 않는다.
- 광고 버튼에서 행동·보상·기간을 표시한다. 사용자가 광고를 선택하지 않아도 기존 게임을 계속 진행할 수 있다.

## 다음 콘텐츠 추천 (아직 미구현)

1. **신화별 도전 과제**: 특정 월드에서 합성 30회, 피버 누적 60초 등 선택 목표로 도감 테두리·대사·배경을 해금한다. 단순 환생 횟수 반복보다 회차마다 할 일을 바꿀 수 있다.
2. **신화 숙련도**: 이미 수집한 외형 재달성 시 숙련도 1단계. 3/5/10단계에 장식·이펙트·칭호를 확정 지급한다. 수익 상승만 무한 누적하면 경제가 무너지므로 상한이 있는 작은 보너스 또는 외형 중심으로 한다.
3. **회차 시작 선택**: 다음 목표 신화 두 후보 중 하나를 선택하게 한다. 희귀 확률 뽑기로 도감 완성 시간을 억지로 늘리기보다 수집 방향을 고르게 한다.
4. **주간 수련**: 기존 필드와 분리된 짧은 챌린지로 재화 제한/자동합성 제한 등 규칙을 바꾼다. 본편 세이브나 과금 재화를 잃지 않도록 별도 상태로 둔다.
5. **수집 세트 보상**: 월영·홍련 등 테마 3종 완성 시 전용 배경/로비 장식. 한정 콘텐츠가 끝나도 추후 얻을 경로를 둔다.

## 과금 제안 (아직 미구현)

- 광고 제거 + 광고 보상 즉시 수령을 이해하기 쉬운 주력 혜택으로 둔다.
- 확정 외형/필드 스킨 묶음과 작은 시작 편의 팩을 검토한다. 필수 신화 도감 완성을 유료 전용으로 막지 않는다.
- 월정액은 실제 일일 콘텐츠가 생긴 뒤 검토한다. 현재 콘텐츠 양에서 구독부터 넣지는 않는다.
- 출시 전에 IAP 거래 ID 중복 지급 방지, 구매 복구, 영수증/서버 검증을 점검한다. 이번 편집기 테스트는 실결제 검증을 포함하지 않는다.

## 밸런스 검증 항목

첫 25단계까지의 시간, 환생 2/3회차 도달 시간, 광고 미사용/사용/피버 활용별 차이, 도감 목표 3종 완성 시간을 각각 기록한다. 목표 시간을 정하기 전에는 현재 숫자를 최종 밸런스로 간주하지 않는다.

## 편집기 검증 결과

- Unity 2022.3.62f3 컴파일 성공. 기존 SaveManager.autoCloudSave 미사용 경고 1건은 남아 있다.
- 격리된 preview scene에서 실제 매니저 API 검사 155개 통과. 실제 플레이어 save.json은 변경하지 않았다.
- Ingame 씬에 매니저·HUD·외형 참조를 연결하고 저장했다. 원본 패널 이미지 18곳 라운딩.
- 다음 신화 설명을 포함한 환생 안내창 TMP overflow=False, 글자 크기 34 및 버튼 배치를 편집기에서 확인했다.
- 이 검사는 전체 Play Mode, Android 빌드/실기기 터치, 실제 광고·구매·클라우드 복구, 장기 플레이 시간 측정을 포함하지 않는다.
- 수치 변경: Ingame의 GameSystem → IncomeActivityManager. 외형 확장: 같은 오브젝트의 MythicCollectionManager.forms에 고유 ID와 스프라이트를 추가한다. Apply Scene Polish는 초기 3종 설정을 재적용하므로 카탈로그를 확장했다면 편집기 유틸리티도 함께 갱신한다.
