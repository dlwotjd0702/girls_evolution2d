# 기획/뉘앙스 기록용 메모

이 문서는 “현재 기준”으로 의도와 밸런싱 감각을 기록합니다.
기능 설명보다 **의도/톤/수치 감각** 위주로 요약합니다.

## 핵심 톤
- 빠른 합성과 점진 성장
- 25단계 도달 시 “환생 맛”이 나는 보상
- 반복 플레이에서 영구 보정의 체감

## 환생 포인트 감각(현재 기준)
- 25단계 스택:
  - 1레벨 2500
  - 이후 레벨마다 +1000
- 하위 단계: 25단계 기준에서 단계 내려갈 때마다 1/2
- 강화 레벨 보정: 각 강화 레벨당 100 포인트
- 최종 적용: 환생 포인트 배율로 곱

## 환생 상점 비용 감각(현재 기준)
- 코어 4종: 베이스 300, 성장 1.15 (two-step은 1.25)
- 자동 소환/합성: 베이스 600, 성장 1.22
- 나머지 Plus: 베이스 300, 성장 1.12
- 목표: 25단계 환생 1회 기준으로 여러 번 구매 가능

## 전투/수익 감각
- 기본 수익은 레벨 기반 지수 성장
- 25단계 스택은 최종 단계 수익에 스택 곱
- 계승 등급 × 환생 상점 배수 적용
- 클릭 보너스는 (기본 10% + 레벨당 1%) × 환생 클릭 배수

## 안정성/품질 메모
- 로컬 저장(JSON) + PlayerPrefs 병행
- 클라우드 저장은 수동 적용, 로그인/광고는 재시도 루프
- +2단 도약 확률은 20% cap

## 앞으로 볼 포인트
- 환생 직후 체감(첫 1~2회 구매 체감)
- 하위 단계 기여도 과소/과대 여부
- 광고/클라우드 상태 UI의 즉시 반영 여부
